# Contributing to Awesome Claude Code

Thanks for your interest in contributing! This list aims to be the best curated resource for Claude Code users.

## Guidelines

### What belongs here

- Tools, skills, and MCP servers that work with Claude Code
- Tutorials and articles that teach something specific and useful
- Configuration examples that solve real problems
- Community resources that are actively maintained

### What doesn't belong

- Self-promotional links without real value
- Duplicate resources (check existing entries first)
- Outdated or broken links
- Generic AI/LLM resources not specific to Claude Code

### How to contribute

1. Fork this repository
2. Add your resource to the appropriate section
3. Use the format: `[Name](link) - One-line description ending with a period.`
4. Make sure the link works
5. Open a pull request with a clear title

### Quality standards

- One resource per pull request (easier to review)
- Description should explain what it does, not why it's great
- Links should point to the primary source (GitHub repo, official docs)
- No affiliate links

### Reporting issues

- Broken link? Open an issue with the link and section name
- Wrong category? Open an issue suggesting the move
- Missing resource? Open a PR or an issue describing it

## Code of Conduct

Be respectful. This is a community resource. We welcome contributions from everyone regardless of experience level.
